# Global-Sales-Performance-Dashboard
project Overview

This project analyzes global sales data to identify key business insights such as revenue trends, top-performing regions, and product performance.
An interactive dashboard was built to help stakeholders quickly understand sales performance and make data-driven decisions.

🎯 Project Objectives
Analyze overall sales performance
Identify top-selling products

dashboards
📂 Dataset

The dataset used for this project was collected from Kaggle.

🛠 Tools & Technologies Used
Power BI – Dashboard visualization
Power Query – Data cleaning and transformation

Trends
📊 Key Visualizations

The dashboard includes:

KPI Cards (Total Sales, Profit, Orders)
Bar Charts for Category Sales
Line Chart for Sales Trend
Pie Chart for Region Distribution
